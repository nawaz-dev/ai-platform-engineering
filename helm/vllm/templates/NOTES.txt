{{- $name := include "vllm.fullname" . -}}
vLLM inference service: {{ $name }}
Namespace: {{ .Release.Namespace }}

{{ if .Values.deployToCluster -}}
Wait for the model server (the first model download can take several minutes):
  kubectl --namespace {{ .Release.Namespace }} rollout status deployment/{{ $name }}

Inspect model loading and GPU initialization:
  kubectl --namespace {{ .Release.Namespace }} logs deployment/{{ $name }} -c {{ $name }} --follow
{{ else -}}
Deployment creation is disabled by deployToCluster=false.
{{ end }}
Connect to the inference API from your machine:
  kubectl --namespace {{ .Release.Namespace }} port-forward service/{{ $name }} 8000:{{ .Values.service.ServicePort }}

Check readiness and discover the served model IDs:
  curl http://127.0.0.1:8000/health
  curl http://127.0.0.1:8000/v1/models

Use http://127.0.0.1:8000/v1 as the OpenAI-compatible API base URL.
If API-key authentication is configured, include an Authorization: Bearer header.

{{- end }}
{{ end }}
